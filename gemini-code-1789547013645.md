# Multi-Document RAG Assistant

A fast, modern Retrieval-Augmented Generation (RAG) chat application that allows users to upload multiple documents (`PDF`, `TXT`, `DOCX`) and get context-aware answers powered by **Groq's `openai/gpt-oss-120b`** model.

## Features
- **Multi-File Support**: Ingests `.pdf`, `.txt`, and `.docx` files simultaneously.
- **Fast Vector Search**: Uses HuggingFace embeddings (`all-MiniLM-L6-v2`) and in-memory **FAISS**.
- **High Performance LLM**: Powered by Groq infrastructure using `openai/gpt-oss-120b`.
- **Source Attributions**: Clear, expandable citations indicating exact source file and page numbers.
- **Glassmorphism UI**: Custom styled dark-theme Streamlit interface.

## Local Development Setup

### 1. Prerequisites
- Python 3.10 or higher.
- A Groq API Key (get one at [console.groq.com](https://console.groq.com)).

### 2. Environment Setup
```bash
# Clone repository
git clone [https://github.com/your-username/multi-doc-rag.git](https://github.com/your-username/multi-doc-rag.git)
cd multi-doc-rag

# Create virtual environment

source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
